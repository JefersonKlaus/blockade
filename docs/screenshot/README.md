# Store pictures

Screenshots of the real app for the Google Play and App Store listings. Each folder
matches one upload slot in the store console. All files are PNG, RGB (no transparency),
at the exact pixel size the store asks for.

> **Language:** these pictures show the app in **Portuguese**, so they belong to the
> Portuguese (Brazil) store listing. The app is in English by default, so the English
> (default) listing needs an English set of the same pictures.

| Folder / file | Size (px) | Where to upload |
|---|---|---|
| `google-play/phone/` | 1080 × 1920 | Play Console → Main store listing → Phone screenshots |
| `google-play/tablet-7-inch/` | 1200 × 1920 | Play Console → 7-inch tablet screenshots |
| `google-play/tablet-10-inch/` | 1600 × 2560 | Play Console → 10-inch tablet screenshots |
| `google-play/feature-graphic.png` | 1024 × 500 | Play Console → Feature graphic (required) |
| `app-store/iphone-6.9-inch/` | 1290 × 2796 | App Store Connect → iPhone 6.9" display |
| `app-store/ipad-13-inch/` | 2048 × 2732 | App Store Connect → iPad 13" display |

Every screenshot folder has the same 7 pictures, numbered in the suggested upload order
(the stores show the first ones first):

| File | What it shows |
|---|---|
| `01_game.png` | A game against the phone: your turn (blue screen), a square chosen and the blocks it would turn highlighted in yellow |
| `02_two.png` | Two players on the same device: Laranja's turn (orange screen) |
| `03_question.png` | A game with math: the question to answer before placing the block |
| `04_menu.png` | The menu: who plays, how smart the phone is, math, Jogar! |
| `05_mathpage.png` | *Praticar matemática*: the signs and the times tables |
| `06_tutorial.png` | The *Como jogar* window shown the first time |
| `07_win.png` | The end of a game: *Você venceu!* with the record for that level |

The pictures were taken from the real app running in a browser at each device's size and
pixel density (for example 430 × 932 at 3× for the iPhone), so everything on them is
exactly what the app draws. They show only the app, without a phone status bar.

Take them again whenever the screens change, so the stores never show an old version.
